# Bayern-Munich-React-Website
A modern and fully responsive React web application inspired by FC Bayern Munich, rebuilt from an original HTML/CSS 
version into a dynamic, interactive experience.
# About-The-Project
This project is a complete redesign and upgrade of my previous static website. It was rebuilt using React to
improve structure, perfomance, and user experience with modern UI techniques and animations.
# Features
• Fully responsive design( mobile, tablet, desktop )
• Smooth page transition and animations
• Interactive UI components
• Image sliders for highlights and moments
• Modern layout with resusable components
• Improved navigation experience
# Technologies Used 
• React.js
• React Router DOM
• Swiper.js(for sliders)
• Framer Motion (animation)
• BootStrap (styling & icons)
• CSS3
